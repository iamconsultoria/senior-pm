description: Produce a decision-grade status report for a steering committee or sponsor
---

Write a status report using the `senior-project-manager` skill and `templates/status-report.md`.

Project and audience: $ARGUMENTS

If the project lives in a connected PM tool, use `pm-tool-operations` to pull the live position
first. Reconcile the tool against reality — the board is a claim, not a fact.

Lead with the one thing the reader must know, and put the decisions you need from them second,
never last. Convert data into information: a steering committee will not do the analysis for
you, and a project looks fine until it does not.

Only escalate risks this audience can act on, and state the ask. Close with the assumptions the
report rests on.
